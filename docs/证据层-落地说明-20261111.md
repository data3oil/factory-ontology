# 证据层落地说明（evidence_kb，2026-11-11）

## 一 这是什么

给工厂本体补一层"可逐字核对的原文出处"。它与既有 RAG 分工，不替换：

| 层 | 负责 | 入口 |
|---|---|---|
| 既有 bm25_retrieval / 向量 / RRF | 哪个实体、哪类知识相关 | /api/ask、/api/stats |
| 证据层（本次新增） | 这段原文在哪、第几行、能否核对 | /api/evidence/* |

技术上是纯标准库：SQLite FTS5 + 中文重叠二元组 + 行级回引，零模型、零外部依赖、数据不出厂。库文件独立（codes/data/evidence/<kb>.db，已 gitignore），不动本体与图谱数据。
